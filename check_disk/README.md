Небольшая утилита для проверки свободного места на виртуалке BitrixVM. 
Утилита сделана под коробочный портал Битрикс24. Запускается через cron 3 раза в день.

На портале настроено ежедневное резервное копирование. Утилита будет каждый день проверять свободное место на диске. 
Если значение будет ниже заданного, то сразу будет отправляться уведомление на портал в чат с техническими специалистами.

Команда cron: 0 9,13,17 * * * /home/bitrix/www/local/check_disk/check_disk
